# 更新插件

[返回首页](../README.md) · [首次安装](INSTALL.md)

本项目采用本地加载方式。下载新版本后，需要你更新文件，并在 Chrome 中刷新扩展。**仅刷新 YouTube 页面，不一定会更新扩展后台代码。**

## 保留原目录更新

如果你已经安装过插件，推荐沿用原来那个直接包含 `manifest.json` 的文件夹，这样更容易保留原扩展的身份、密钥设置和浏览器缓存。

1. 等当前翻译任务结束，或点击“停止”并等待当前请求结束。也可关闭“启用翻译”总开关；已经发出的请求仍需完成。先下载需要保留的字幕。
2. 找到原来加载到 Chrome 的插件文件夹。里面应当直接有 `manifest.json`。暂时保留旧文件夹，不要先删除扩展。
3. 下载并完整解压新版本的插件安装 ZIP。
4. 打开新解压的文件夹，将里面的插件文件复制到原目录，选择替换同名文件。复制后，原目录里仍应当直接有 `manifest.json`。
5. 在 Chrome 地址栏打开 `chrome://extensions`。
6. 找到原来的插件，点击卡片上的刷新／重新加载图标。旧版可能仍叫“整句中文字幕 · YouTube”；重新加载后会显示“YIHAO 翻译器 · YouTube 双语字幕”。
7. 查看卡片版本号是否已更新。再回到 YouTube，刷新视频页面。

成功后，卡片应显示 **0.1.4**，视频按钮与面板标题应显示 **YIHAO 翻译器**；原来的密钥若仍显示已配置，就不必再填写。

## 从曾经带有 extension 子文件夹的旧安装包更新

新版本安装包已将 `manifest.json` 放在根目录，减少选错文件夹的情况。旧版本如果加载的是下面这个位置：

```text
原来的解压文件夹/
└─ extension/
   └─ manifest.json
```

请把**新包中直接包含 `manifest.json` 的那一层文件**复制到旧的 `extension` 文件夹里，再刷新扩展。

不要把新文件夹整个再套进旧目录，变成 `extension/新文件夹/manifest.json`。Chrome 仍然会读取原来那一层。

## 如果想换一个安装位置

更换目录可能让 Chrome 将它识别为另一个本地扩展，原来的密钥和缓存不一定随之出现。

先保留旧目录、下载需要的结果，再把新位置作为新扩展加载。确认新扩展可以使用后，再处理旧版本。不要同时启用两个版本，以免页面出现重复按钮或字幕。

## 更新后界面没有变化

按顺序检查：

1. 替换的是 Chrome 原来加载的文件夹吗？里面是否直接有新版 `manifest.json`？
2. 是否在 `chrome://extensions` 点击过扩展的刷新图标？
3. 是否刷新了原来已经打开的 YouTube 视频页？
4. 是否同时开启了另一个旧版本？

如果提示“清单文件缺失或不可读取”，回到原加载目录检查文件层级；[安装教程](INSTALL.md) 有结构示意图。

## 0.1.4 的名称更新

- 产品主名统一为“YIHAO 翻译器”，扩展列表中的全名为“YIHAO 翻译器 · YouTube 双语字幕”。
- 新安装包名为 `YIHAO-Translator-v0.1.4.zip`，GitHub源码包名为 `YIHAO-Translator-GitHub-v0.1.4.zip`。
- 本次改名保留既有存储与缓存标识。继续覆盖原来的已加载目录，再重新加载扩展，可沿用原有数据。

## 已有功能的位置

- 标题旁新增“启用翻译”总开关，默认开启。关闭会隐藏自定义字幕、恢复原生字幕、阻止新翻译，并在已发出的请求完成后暂停后续批次。
- 总开关同步到已打开的 YouTube 页面，刷新或重启浏览器后记住；重新开启会恢复已生成字幕，但未完成翻译需手动点击“继续翻译”。密钥、样式和字幕缓存保留。
- “字幕样式”里的“显示字幕”只控制显示，不会停止翻译。
- 主面板保持“开始翻译”为核心操作。
- 展开“字幕样式”，点击“调整字幕样式”，在页面内分别调整中文主字幕与原文副字幕。
- 共用字幕背景底框默认开启，可以关闭。
- 模型配置与字幕导入移到扩展自己的设置页：`chrome://extensions` → 本扩展“详细信息” → “扩展程序选项”。
- 备用导入在设置页“高级排错”中，需要刷新列表、核对并选择目标视频，再点击“导入到所选视频”，从弹出的窗口选择对应原字幕。

Chrome 的扩展刷新步骤也可参考 [官方教程](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)。
