# 字幕翻译与显示规范

本项目优先保证一句话的意思完整，再处理显示长度。不能把固定时间片直接交给模型翻译，否则容易出现上一条字幕带着下一句话开头的情况。

## 翻译顺序

1. 获取原语言字幕与时间信息，不使用 YouTube 的中文机翻作为翻译底稿。
2. 先分析整份原字幕，识别主题、语气、专业领域、术语和可能的转写错误，生成本片翻译规则。
3. 将原文整理成完整句意，结合上下文分批翻译；每条译文必须对应连续的原文范围。
4. 校验字幕覆盖范围、时间顺序、数字与句末标点，再生成网页字幕和 SRT。

## 中文表达

- 使用自然、简洁的口语或讲解语言，避免翻译腔和无意义的扩写。
- 同一术语保持一致。教程中的软件名称、界面项目、命令和快捷键，应结合上下文保留英文或使用通行中文名称。
- 不补充原文没有的观点、步骤或事实。可疑的自动转写须结合上下文谨慎处理，并记录待核对项。
- 每条字幕表达完整句意，不把下一句话的开头放在上一条末尾。通常使用“。”结尾，疑问句、感叹句分别使用“？”“！”。
- 优先完整表达。极长原句可能仍然形成较长字幕；当前没有保证每条字幕固定字数，也没有提供人工逐句校对编辑器。

模型提示词见根目录 `sentence-prompt.txt`，程序中的结构与数字校验见 `core.js`。提示词和校验能减少错误，不能保证每次输出都正确。

## 时间对应

字幕时间取自原字幕。JSON3 中存在词级起点时优先采用；词尾时间根据后续起点估算。只有 SRT/VTT 句段时间时，句内时间也需要估算。当前不分析音频进行强制对齐，因此可能有少量提前或延后。

## 默认显示

- 中文主字幕：28px，白色、加粗、有文字投影。
- 原文副字幕：显示在中文下方，字号为中文的 60%，默认不加粗，颜色稍弱。
- 两行共用暗色背景，用户可在“字幕样式”里关闭；关闭背景后文字投影仍然保留。
- “调整字幕样式”分别设置中文与原文的字号或比例、颜色、加粗和投影。修改立即生效，“恢复默认”重置文字样式，背景开关单独保留。
- 全屏时两种字幕同步放大，并保持字号比例。

下载的 SRT 只保存文字和时间，不保存网页中的颜色、投影、字号或背景。其他播放器如何显示，由播放器设置决定。
