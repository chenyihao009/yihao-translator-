# 隐私与权限说明

## 哪些数据留在浏览器

- API Key保存在Chrome扩展本地存储，不保存在仓库或安装包中，也不写入YouTube网页。
- 字幕、全文翻译方案、部分API用量、译文、任务进度、样式偏好和“启用翻译”总开关状态保存在扩展的本地存储／IndexedDB。
- 没有本项目运营的服务器，没有项目账号、广告统计或自动遥测。

“本地存储”指这个浏览器配置中的扩展数据，不是加密保险库；不能把自己浏览器的资料文件当源码上传。

## 哪些内容会通过网络发送

| 目标 | 用途与内容 |
|---|---|
| YouTube | 获取当前视频公开可访问的字幕和播放器信息。网页请求可使用当前登录会话；另有不带登录Cookie的兼容请求。没有Cookie导出功能。 |
| `https://api.deepseek.com/chat/completions` | 密钥作为请求认证；字幕正文、视频ID、标题、作者／频道、时长等已有元信息，以及模型生成的方案和上下文，用于翻译。 |
| 你主动打开的官方帮助页面 | 仅在点击链接时打开，按该服务自身规则处理。 |

项目不能代替第三方服务作数据保留承诺。请查看[DeepSeek官方资料](https://api-docs.deepseek.com/)及其平台政策。

## 为什么需要这些Chrome权限

| 权限 | 原因 |
|---|---|
| `storage`、`unlimitedStorage` | 保存你的设置、密钥、字幕和翻译进度；较长字幕可能超出普通存储额度。 |
| `scripting` | 在当前YouTube页面读取播放器提供的字幕信息。 |
| `offscreen` | 在浏览器内部运行翻译工作线程，无需打开独立程序。 |
| `downloads` | 用户点击时下载字幕文件。 |
| YouTube主机权限 | 获取字幕并注入浮动面板、字幕显示层。 |
| DeepSeek主机权限 | 在浏览器内直接调用官方翻译API。 |

没有申请读取所有网站的权限。

## 清理与反馈

- 临时停用：关闭标题旁的“启用翻译”总开关。它会同步到已打开的YouTube页面并记住状态，不删除密钥、样式或字幕缓存。已发出的API请求完成后仍会缓存结果，不能撤回；重新开启不会自动恢复未完成的付费翻译，需手动点击“继续翻译”。
- 仅隐藏字幕：“字幕样式”中的“显示字幕”只控制显示，不停止翻译和API调用。
- 清除密钥：扩展设置页点击“清除本机密钥”，不删除已有字幕缓存；已经发出的API请求不会因此撤回。
- 彻底移除本地数据：在Chrome扩展管理页移除扩展。不要把它当作普通更新步骤；重新安装可能需要重新配置，旧缓存不会自动迁移。
- 反馈只提供版本、现象、必要的公开视频链接和截图。不要提交API Key、Cookie、登录凭据或原始浏览器资料。

公开安装包由文件白名单生成，不应包含任何人的密钥、浏览器配置、私人字幕或测试日志。
