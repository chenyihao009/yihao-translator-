# 配置 DeepSeek API 密钥

[返回安装教程](INSTALL.md) · [返回首页](../README.md)

API 密钥可以理解为“允许插件调用你账户中模型服务的凭证”。本插件没有内置公共密钥，你需要使用自己的 DeepSeek API 账户。模型调用是否收费、账户额度和实际扣费，以开放平台显示为准。

## 1. 打开官方开放平台

打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，完成注册或登录。

请使用开放平台的 **API 密钥和余额**。能够使用聊天网页，不代表已经配置好 API 服务；也不要把账号密码填入插件的密钥框。

## 2. 检查账户是否可以调用 API

在开放平台查看可用余额或额度。需要充值时，按照你账户页面显示的可选金额和支付方式操作，先小额验证即可。

这里不提供固定的“一个视频多少钱”：视频字幕长度、模型思考、输出长度和重试次数都会影响用量。具体价格请查看 [DeepSeek 官方模型与计价说明](https://api-docs.deepseek.com/quick_start/pricing/)。

## 3. 创建并复制密钥

在开放平台找到 **API Keys／API 密钥** 页面，创建一个用于本插件的密钥，并复制完整内容。

保留密钥原样，不要加引号、说明文字或多余换行。平台的具体按钮名称可能调整，以当前页面为准。[官方接入说明](https://api-docs.deepseek.com/) 提供了开放平台密钥入口。

## 4. 在扩展自己的设置页保存

有两种进入方式：

- **首次使用：**在 YouTube 面板点击“开始翻译”。没有密钥时，扩展会打开设置页。
- **以后修改：**打开 `chrome://extensions` → 找到本扩展 → “详细信息” → “扩展程序选项”。

在设置页的 DeepSeek API Key 输入框中粘贴密钥，点击“保存密钥”。看到保存成功的提示后，返回 YouTube 页面，再点击“开始翻译”。

**“已保存”表示密钥已存入浏览器，不代表已经验证余额或成功完成模型调用。** 开始翻译后若出现错误码，请看下方表格。

日常 YouTube 主面板不显示密钥，也不放“模型设置”入口。需要修改密钥时，按上面的扩展管理路径进入。

## 保存后仍不能翻译

| 提示 | 建议操作 |
|---|---|
| 尚未配置密钥 | 确认已点击保存，然后回到视频页重试。 |
| DeepSeek 返回 401 | 重新复制完整密钥；检查是否填错、已被撤销或失效。 |
| DeepSeek 返回 402 | 查看开放平台可用余额。 |
| DeepSeek 返回 429 | 暂停同时运行的任务，稍后再试。 |
| DeepSeek 返回 500／503 | 服务端暂时出错或繁忙，稍后重试。 |

错误码含义参考 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/error_codes/)。如果提示的是“YouTube 字幕获取失败”，应先排查原字幕；更换 DeepSeek 密钥通常不能解决 YouTube 会话问题。

## 密钥保存在哪里

密钥保存在当前 Chrome 配置中的扩展本地存储里。插件调用模型时将其发送至 DeepSeek 官方 API；YouTube 页面中的内容脚本只会知道“是否已配置”，不会取得密钥正文。

上传 GitHub 或报告问题时，不要上传自己的密钥、包含密钥的截图、浏览器用户数据目录或 Cookie。也不需要把密钥写进任何项目文件。

若你不小心公开了密钥，去 DeepSeek 开放平台撤销它，再创建新密钥并在扩展设置页替换。
