# 常见问题

[返回首页](../README.md) · [安装教程](INSTALL.md) · [密钥配置](API_KEY.md) · [更新教程](UPDATE.md)

## 加载时提示“清单文件缺失或不可读取／无法加载清单”

Chrome 选中的文件夹里必须**直接有 `manifest.json`**。

请先完整解压 ZIP，再打开解压后的文件夹查看。如果里面还有一层文件夹，进入那一层，直到看到 `manifest.json`，然后在 Chrome 中选择这一层。不要选择 ZIP 文件，也不要只选外层收纳文件夹。

本版插件安装包将 `manifest.json` 放在根目录。GitHub 的 `Source code (zip)` 解压后可能多出一个仓库名称文件夹，按文件内容判断即可。

## 安装后，YouTube 页面没有“YIHAO 翻译器”按钮

1. 打开 `chrome://extensions`，确认本扩展的开关已打开。
2. 打开普通 `www.youtube.com/watch?v=...` 视频页。
3. 刷新视频页面。安装前已打开的标签页必须刷新。
4. 也可以点击 Chrome 工具栏中的本扩展图标，打开页面内面板。

当前没有完成 Shorts、直播、画中画等场景的验证。更新后仍然没有按钮，请先按 [更新教程](UPDATE.md) 刷新扩展本身，再刷新视频页。

## 我已经登录 YouTube，为什么还是取不到字幕

登录可能有帮助，但不能保证每个视频都成功。先在这个视频上开启 YouTube 自带的原语言字幕，确认它本来就能正常显示，再重试插件。

当前版本在隔离、未登录的测试浏览器中，可以列出字幕轨道，但自动下载没有通过；独立接口探测还遇到过平台要求登录或确认当前会话。插件不会绕过这些要求。

仍失败时，使用设置页中的备用入口：`chrome://extensions` → 本扩展“详细信息” → “扩展程序选项” → “高级排错”。点击“刷新视频列表”并核对、选择目标视频，再点击“导入到所选视频”，从弹出的窗口选择对应的原字幕文件。[完整导入步骤见安装教程](INSTALL.md)。

## 无字幕的视频也能翻译吗

当前不支持。插件需要原字幕或你导入的字幕文件；没有字幕的视频要先做语音识别，这项能力尚未接入。

## 为什么点开始后，没有马上出现中文

插件会先阅读字幕全文，再分批翻译，并在每批显示前做一次AI审校。最初会有等待，之后生成的字幕逐步出现。面板显示“正在检查字幕”时仍在处理。当前播放位置尚未处理到时，也暂时不会有中文。

请看面板状态是否仍在变化，不要反复开启同一个任务。视频越长、接口越繁忙，等待可能越久。出现错误提示后，再根据提示处理并重试。

## 有中文，但没有原文；或者字幕都不见了

先确认标题旁的“启用翻译”总开关已打开，再展开“字幕样式”，检查“双语字幕”和“显示字幕”开关；点击“调整字幕样式”，可分别调整中文和原文的样式。默认中文在上、原文在下，原文字号是中文的 60%。“暗色背景”默认开启，控制两行共用的背景底框。

也请确认当前播放位置处于已翻译的片段。广告播放或播放器出现错误时，插件会隐藏翻译字幕，避免把正文字幕叠在广告或错误提示上。

## “启用翻译”和“显示字幕”有什么区别

- **启用翻译：**标题旁的总开关，默认开启。关闭会隐藏自定义字幕、恢复 YouTube 原生字幕、阻止新翻译，并在当前已发出的 API 请求完成后暂停后续批次。
- **显示字幕：**在“字幕样式”里，只控制自定义字幕是否显示，翻译任务仍会继续，仍可能产生 API 费用。

总开关会同步到已经打开的 YouTube 页面，刷新页面或重启浏览器后仍记住状态。关闭总开关不会删除密钥、样式或字幕缓存。

## 重新开启总开关，会自动继续扣费翻译吗

不会。重新开启“启用翻译”会恢复已生成字幕；未完成的翻译需要你再点击“继续翻译”。关闭前已发出的 API 请求仍会完成并缓存结果，相关调用不能撤回，仍可能计费。

## 哪里修改密钥，哪里导入字幕

这些功能不放在日常主面板里。

在 Chrome 地址栏打开 `chrome://extensions`，找到本扩展，进入“详细信息” → “扩展程序选项”。密钥在设置页配置；字幕导入在“高级排错”中。

导入时务必核对目标视频标题，尤其是同时开了多个 YouTube 视频的时候。

## SRT、VTT、JSON3 是什么

它们都是字幕文件格式，插件可在高级排错中导入：

- **SRT：**常见的字幕文本格式，包含序号、时间和文字。
- **VTT：**网页中常见的字幕格式。
- **JSON3：**YouTube 使用的一种字幕数据格式，有时含更详细的单词起点。

请使用与目标视频对应的原语言字幕。自带的 [demo.en.srt](../samples/demo.en.srt) 是自编格式示例，不是任何 YouTube 视频的配套字幕。

## 字幕为什么可能有一点提前或滞后

有逐词信息时，插件用原字幕的单词起点确定边界，句尾根据下一词起点估算；没有逐词信息的 SRT、VTT，句内时间需要估算。当前未做音频强制对齐，因此不能保证逐词精准同步。

## 翻译会不会完全准确

不能保证。0.1.6增加了一次独立AI审校，对照原文检查句意、断句、术语、表达和可读性，但同一个模型仍可能漏检或误判。原始自动字幕本身也可能把人名、数字或快捷键听错，文字审校未必能恢复原音。

教程中的关键操作、专业术语和数值，建议结合画面与原音抽查。程序检查与AI审校通过，都不等于人工审核。

## 为什么要先翻译，再让模型检查一次

初译和审校侧重点不同：初译根据全文方案组织译文，审校再对照原文找遗漏、误译、错误断句和术语不一致。两次使用同一套[五条字幕规范](字幕规范.md)。没有发现实质问题时保留初译，不要求模型为了“润色”反复改写。

每批通常增加一次API请求，会增加等待和费用；不做无限轮自我修改。审校出错或输出被截断时会使用初译，继续处理下一批，不要求用户修复。

## 为什么不再显示“模型改写原文”或一般的质量报错

0.1.7改为优先生成可用字幕。英文从原始字幕恢复；数字写法、标点、分句和审校疑点由程序或AI内部处理，不要求普通用户看懂技术错误。审校建议有问题就保留初译，不会阻塞整片。

普通分句失败时会自动修复，再不行就用程序固定原文片段，仅让模型翻译中文。极端情况下断句和表达可能不够理想，优先让你能继续观看。网络断开、密钥不可用、账户余额不足或没有原字幕时，仍需按界面提示处理，插件不能凭空生成没有取得的译文。

## 插件免费，为什么还需要 DeepSeek 余额

本地加载插件和调用第三方模型是两件事。插件使用你自己的 DeepSeek API 账户，模型调用费用或额度以开放平台显示为准，项目不提供公共密钥。[配置说明](API_KEY.md) 中有官方入口。

## 出现 DeepSeek 401、402、429 等错误

| 错误码 | 优先检查 |
|---|---|
| 401 | 密钥是否完整、有效。 |
| 402 | 开放平台余额是否充足。 |
| 429 | 是否同时发起太多任务；稍后重试。 |
| 500／503 | 服务端暂时出错或繁忙；稍后重试。 |

参考 [DeepSeek 官方错误码说明](https://api-docs.deepseek.com/quick_start/error_codes/)。

## 点击停止后，为什么没有立刻停下

“停止”会在当前 API 请求结束后生效，已经发出的请求不会被撤回。已完成批次会保留，之后可以点击“继续翻译”。若想同时隐藏自定义字幕、恢复原生字幕并暂停翻译，请关闭标题旁的“启用翻译”总开关。

## 下载的字幕为什么只有前面一部分

下载的是当前已经完成的内容。等待本次输入全部处理完成后，再下载最终结果。如果导入的原字幕本来只有某一段，翻译结果也只覆盖那一段。

## 可以关掉浏览器，之后继续吗

已经完成的批次、原字幕以及等待审校的初译会保存到浏览器缓存中。关闭浏览器会中断正在运行的处理；重新打开同一视频后，可根据面板提示继续。原字幕缓存有效时会直接复用；缓存缺失或无效时，才重新获取或需要你导入同一个文件。

关闭浏览器不能撤回已经发出的 API 请求。

## 想报告问题，需要提供什么

在项目的 GitHub Issues 中描述：

- 扩展版本、Chrome 版本和操作系统。
- 出问题的步骤，以及面板上的完整错误提示。
- 公开的视频链接，以及 YouTube 原生字幕是否正常。
- 是否为导入字幕、文件格式是什么。
- 必要的截图；先确认画面里没有密钥或其他个人信息。

不需要上传密钥、Cookie 或浏览器用户数据目录。


## 英文字幕词序交错或重复怎么办

0.1.5修复了把YouTube滚动字幕按词时间重新排序的问题。请更新完整文件并重新生成该视频，旧任务不会直接套用到新词索引。真实重复词会保留；时钟冲突只能估算，尚未做音频对齐。

## 中文数字与原文写法不同，会被拒绝吗

0.1.5支持明确等值的中文数词、数量级、百分数、常见单位换算及科学计数；不要求照抄阿拉伯数字。初译中的数值疑点会交给AI审校处理，审校危险改值建议仍可拒绝；内部记录不会阻断普通使用。它不能证明所有数值语义都正确，请抽查数字、单位及快捷键。

## 模型达到输出长度上限后如何处理

0.1.5日常翻译关闭思考，截断后会有限次数缩小批次。0.1.7在最低窗口增加一次预算后仍截断时，会自动切换到简单分块翻译，不会因为长度校验直接卡住。已完成批次保留。不要把输出截断、内容审核、服务资源不足当成同一种错误。

## 可以使用其他模型的Key吗

当前公开版只支持DeepSeek官方API。你需要在扩展设置页填写自己的Key，不需要项目提供者代充或保管。其他服务的Key不能直接粘贴使用。当前版本优先降低小白的配置负担、稳定完成翻译；兼容其他API暂不提供，不要随意修改地址或把第三方Key填入DeepSeek配置。
